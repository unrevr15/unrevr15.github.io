# US Macro Dashboard (static build)

https://unrevr15.github.io

이 저장소는 비공개 저장소 `us-macro-dashboard`의 정적 사이트 생성기가 만든 결과물만 담는다. 직접 고치지 않는다(게시할 때마다 커밋 하나로 통째로 바뀐다).

- `index.html`, `assets/`: 대시보드 SPA (정적 데이터 모드)
- `data/`: 게시 시점의 API 응답 스냅샷 (`data/manifest.json`에 기준 시각)
- `energy/`: 에너지 공급망 리서치와 밸류체인 기업 페이지 (`energy/live-data.js`가 자동 갱신 시세)
